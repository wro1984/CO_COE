# Monitor COE

App do celular com o COE e o Re-teste de hoje, até agora: <https://wro1984.github.io/CO_COE/>.

- Abre pelo **HUB dos apps** (<https://wro1984.github.io/>), com a mesma matrícula e chave. Quem vê é definido no perfil do HUB.
- Os números são publicados pelo MAPI (Comunicação → COE · App), cifrados. Este repositório é público e não guarda nada aberto.
- Para mantenedores: leia o `CLAUDE.md` antes de mudar qualquer coisa.
